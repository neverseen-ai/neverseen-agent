What the agent tries to mask

Computed from the patterns in pkg/pii: every locale, whatever a deployment loads. Regenerate with go run ./.claude/skills/catalogue-report after changing the catalogue.

Coverage score

How few shapes a category's value can take, so how far one set of regular expressions can be trusted to catch every one of them. It is computed from the structure of the patterns, not measured on data: it is not a precision or a recall (make bench-accuracy measures those).

  • Starts at 100.
  • −15 when only the shape vouches for the value: no run of 3+ fixed characters in the value itself (sk-, ://), or of 2 before a bounded value of 16+ characters (SK and 32 hex digits) and no check beyond the shape (checksum, parser).
  • −25 for free text: a value of open length that spans words. −10 for an open length within one word.
  • −5 per unanchored form past the first (at most −30): every form is one more case somebody had to write down. A notation whose every sample value has the shape of a value another notation already reads is one more context for that form — another way to find it — and costs nothing.
  • −5 per country past the first (at most −20).
  • −10 when source code satisfies the shape on its own (dates, runs of digits).
  • Never below 5. A literal in the context around the value (password=) anchors the match, not the value, and earns nothing.

Secrets (4 below 100%, 128 at 100%)

Credentials: the agent replaces them with a token and never a stand-in, and none can be switched off.
