# Corpus de test — différentes formes de secrets

Ce document simule un ensemble de fichiers, configurations, logs, commentaires et extraits de code dans lesquels un détecteur de secrets pourrait rencontrer différentes représentations de credentials. Toutes les valeurs ci-dessous sont fictives et destinées exclusivement aux tests.

---

## 74. Objectif du corpus

Ce corpus doit permettre d'évaluer notamment :

* la détection par **nom de variable** ;
* la détection par **regex** ;
* la détection par **entropie** ;
* la détection des secrets dans plusieurs **formats de fichiers** ;
* la détection des secrets dans du **code source** ;
* la détection dans les **fichiers de configuration** ;
* la détection dans les **logs** ;
* la détection dans les **headers HTTP** ;
* la détection dans les **URLs** ;
* la détection des secrets **Base64** ;
* la détection des secrets **hexadécimaux** ;
* la détection de credentials **multilignes** ;
* la détection de valeurs **concaténées ou interpolées** ;
* la gestion des **majuscules/minuscules** ;
* la gestion des différents **séparateurs** ;
* la distinction entre **vrais positifs** et **faux positifs** ;
* la reconnaissance des **placeholders** et valeurs de documentation.

Toutes les valeurs `EXAMPLE_*`, `YOUR_*`, `CHANGE_ME`, `DUMMY`, `FAKE` et valeurs similaires de ce corpus sont volontairement synthétiques.
