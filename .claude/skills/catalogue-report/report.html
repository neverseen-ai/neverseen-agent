Coverage score

How few shapes a category's value can take, so how far one set of regular expressions can be trusted to catch every one of them. It is computed from the structure of the patterns, not measured on data: it is not a precision or a recall (make bench-accuracy measures those).

  • Starts at 100.
  • −{{.Penalty.ShapeOnly}} when only the shape vouches for the value: no run of {{.Penalty.MinAnchor}}+ fixed characters in the value itself (sk-, ://), or of {{.Penalty.MinShortAnchor}} before a bounded value of {{.Penalty.MinFixedLength}}+ characters (SK and 32 hex digits) and no check beyond the shape (checksum, parser).
  • −{{.Penalty.FreeText}} for free text: a value of open length that spans words. −{{.Penalty.OpenLength}} for an open length within one word.
  • −{{.Penalty.PerForm}} per unanchored form past the first (at most −{{.Penalty.CapForms}}): every form is one more case somebody had to write down. A notation whose every sample value has the shape of a value another notation already reads is one more context for that form — another way to find it — and costs nothing.
  • −{{.Penalty.PerCountry}} per country past the first (at most −{{.Penalty.CapCountries}}).
  • −{{.Penalty.Noisy}} when source code satisfies the shape on its own (dates, runs of digits).
  • Never below {{.Penalty.Floor}}. A literal in the context around the value (password=) anchors the match, not the value, and earns nothing.
